# 공통 조회와 관리

공급자 데이터 해석·기존 프로세스 실행·상태 모델·로컬 관리 계약을 소유한다. SwiftUI·AppKit 창·앱 현지화·사용자 확인 UI는 소유하지 않는다. 플랫폼 공통 동작은 TestsLinux의 가짜 입력으로 검증한다.

새 로컬 관리 상태는 schemaVersion·runtimeRole·proxy.running·dashboard.url만 투영한다. 목록 응답이 가능해도 관리 권한을 얻지 않는다. 변경 직전에 역할을 다시 확인하고 오류는 출력·경로·비밀값을 담지 않는 닫힌 종류로 돌려준다.

생성 비밀값은 메타데이터와 다른 타입에 두고 Codable·일반 디버그 반사에서 노출하지 않는다. 셸 없는 인수 배열을 쓰고 생성 이름과 ID를 검증한다. 불명확한 변경 응답에는 자동 재시도를 붙이지 않는다.

이름 변경은 지원 설치의 기존 관리 클라이언트를 제한된 번들 보조 실행기에서 사용한다. 입력은 ID·이름뿐이며 서버·인증값을 사용자 입력으로 받지 않는다. ID를 이름으로 재해석하는 CLI로 대체하지 않는다. 테스트는 합성 설치·가짜 모듈만 사용한다.

추가 테스트에는 역할 변경·누락 필드·중복 ID·동명 키·출력 제한·잘못된 성공 응답·비밀 포함 오류를 넣는다. 프로세스 수명 변경은 화면 취소 이후 자연 종료와 하위 프로세스 정리를 함께 확인한다. 대시보드 주소 정책은 순수 테스트로 HTTP loopback·자격 포함 주소·origin 이동을 검증한다.
