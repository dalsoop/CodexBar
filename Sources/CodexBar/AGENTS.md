# 앱 UI와 수명

설정 탐색·사용량 표시·메뉴·알림·창과 사용자의 명시적 동작을 소유한다. 공통 응답 해석과 관리 프로토콜은 Core에 두며 UI에서 원시 subprocess 응답이나 Opencodex 자격 파일을 읽지 않는다.

생성 작업과 결과는 앱 수명의 상태에 둔다. 화면을 다시 만들거나 다른 설정으로 이동해도 변경을 다시 보내지 않는다. 비밀값은 일시 결과에만 두고 Codable 설정·공유 snapshot·로그로 보내지 않는다. 생성 결과 닫기와 창 닫기는 각각 비밀값·웹 세션 해제의 경계다.

설정 위치를 추가하면 토큰 왕복과 탐색 이력 테스트를 갱신한다. 문자열은 L 기반 현지화를 사용하고 영어·한국어와 전체 완전성 대상 카탈로그를 같은 키 집합으로 유지한다. 공급자별 계정 카드는 해당 공급자 신원만 사용한다.

UI 테스트는 메모리 설정·주입된 관리 계층·가짜 pasteboard·가짜 창을 사용한다. 실제 Keychain·NSStatusBar·공용 clipboard를 필요 없이 구성하지 않는다. 응답 순서 역전·중복 클릭·생성 중 화면 이동·변경 성공 후 조회 실패·창 재사용과 닫기 후 세션 해제를 확인한다.
