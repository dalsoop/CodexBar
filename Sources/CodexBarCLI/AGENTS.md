# 명령행 인터페이스

Commander 명령 해석·텍스트와 JSON 출력·기존 config 연결을 소유한다. 앱 창·설정 탐색·네이티브 키 전달 화면을 생성하지 않는다. 공급자 조회와 해석은 Core를 사용하며 앱의 전역 상태를 복제하지 않는다.

usage·cost·serve 출력은 선택한 공급자와 계정 범위를 보존한다. 제공되지 않은 사용량을 0이나 비용으로 만들지 않으며 부분 기록과 실패를 성공한 빈 결과로 바꾸지 않는다. JSON은 원시 오류 출력과 섞이지 않는 하나의 문서여야 한다.

명령 회귀는 가짜 실행 파일·합성 config·contained sessions로 검증한다. 실계정 usage나 브라우저 쿠키 가져오기를 일반 빌드 확인에 사용하지 않는다. CLI 자격 캐시는 기존 실행 파일·서명 검증 경계를 유지하고 외부 symlink 별칭 때문에 신뢰 대상을 넓히지 않는다.
