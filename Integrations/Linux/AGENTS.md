# Linux 데스크톱

Qt 6 C++·QML 데스크톱의 창·polling·알림·로컬 IPC·사용자 설정을 소유한다. 공급자 인증과 조회는 별도 Swift CLI에 맡기며 macOS 앱·Keychain에 의존하거나 별도 키 발급 서버를 만들지 않는다. Omarchy는 같은 backend의 표시 어댑터다.

공급자 조회 스트림과 비용 조회 스트림은 각각 겹치지 않게 실행한다. 실패한 공급자는 이전 결과와 stale 표시를 보존하고 선택이 바뀌면 이전 응답을 폐기한다. 창 닫기는 backend 종료가 아니다. 같은 사용자 소켓은 snapshot에 계정 신원·CLI 경로·자격 설정을 내보내지 않는다. 손상된 설정 파일은 자동으로 덮어쓰지 않는다.

인증 버튼은 사용자의 터미널에서 공급자 CLI를 실행하고 출력을 수집하지 않는다. 테스트는 합성 HOME/XDG·가짜 CLI·offscreen Qt로 polling 순서·오류·알림·설정·소켓 응답을 확인한다. 설치 테스트는 관리 설정 symlink의 대상 보존과 기존 어댑터 백업을 검증하며 실제 사용자 설정을 변경하지 않는다.
